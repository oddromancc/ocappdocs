## Описание операций

### Описание всех выполняемых функций, задач, комплексов задач, процедур

#### Создание резюме

Список действий для создания резюме:

- Убедитесь, что находитесь на вкладке Резюме по адресу `/`
- Нажмите на кнопку "Добавить резюме"
- Выберите навыки кандидата.
- Введите данные кандидата, включая:
    - Должность, на которую претендует кандидат
    - Описание
    - Стаж
    - Образование
    - Минимальная желаемая заработная плата
- Нажмите на кнопку "Создать резюме"

#### Создание вакансии

Список действий для создания вакансии:

- Убедитесь, что находитесь на вкладке Вакансии по адресу `/jobs`
- Нажмите на кнопку "Добавить вакансию"
- Выберите навыки, необходимые для вакансии.
- Введите требования вакансии, включая:
    - Название
    - Описание
    - Стаж
    - Образование
    - Минимальная заработная плата
- Нажмите на кнопку "Создать вакансию"
